# MIDI Output Setup & Integration Guides (End-User)

## Overview

This guide explains how to connect the minimal-music MIDI generator to your software synth or DAW and what MIDI messages it emits. You’ll learn how to route the program’s output port into your synth, and understand exactly which messages—Note On, Note Off (via velocity 0), and all-notes-off—are sent, on which channel, and with what velocity.

## Connecting to a Synth or DAW

1. Launch the generator. It enumerates all available MIDI output devices via PortMidi and opens the selected device with zero latency:

```cpp
   err = Pm_OpenOutput(
       &global_pPmStream,
       midioutputdeviceid,
       NULL,
       512,
       NULL,
       NULL,
       0    // zero latency
   );
```

1. In your DAW or virtual port utility (e.g. loopMIDI, MIDI Yoke), create or identify the port named exactly as passed on the command line (default “Out To MIDI Yoke:  1”).

1. In your synth/DAW, set its MIDI input to listen on that port and on the same MIDI channel specified when launching the generator (0–15).

## MIDI Messages Sent by the Generator

### Status Byte and Channel

All note messages use status byte `0x90` (Note On) plus the zero-based channel number. For example, on channel 0 the status byte is `0x90`; on channel 1 it is `0x91`, and so on.

### Note On

When a note is played, a Note On message with velocity 100 is sent.

```cpp
PmEvent* pPmEvent = new PmEvent;
pPmEvent->timestamp = 0;
pPmEvent->message   = Pm_Message(
    0x90 + outputmidichannel,  // status = Note On on chosen channel
    midinotenumber,            // MIDI note number (0–127)
    100                        // velocity
);
global_noteonmap[midinotenumber] = pPmEvent;
```

### Note Off

To turn a note off, the program sends a Note On message with velocity 0 on the same channel. This is a standard MIDI convention for note-off.

```cpp
PmEvent* pPmEvent = new PmEvent;
pPmEvent->timestamp = 0;
pPmEvent->message   = Pm_Message(
    0x90 + outputmidichannel,  // status = Note On (used as Note Off)
    midinotenumber,            // same note
    0                          // velocity 0 signals Note Off
);
global_noteoffmap[midinotenumber] = pPmEvent;
```

When it’s time to send the event, `Pm_Write(global_pPmStream, pPmEvent, 1)` is called.

### All-Notes-Off

On termination (or when explicitly invoked), the generator loops through all possible note numbers (0–127) and sends velocity 0 messages to ensure no hanging notes remain:

```cpp
PmEvent allOffEvent;
allOffEvent.timestamp = 0;
for (int note = 0; note < 128; ++note) {
    allOffEvent.message = Pm_Message(
        0x90 + global_outputmidichannel,
        note,
        0
    );
    Pm_Write(global_pPmStream, &allOffEvent, 1);
}
```

## DAW/Synth Configuration Tips

- **MIDI Channel**: Verify your synth is set to the same channel passed as `outputmidichannel`. Channels are zero-based in code (0 = MIDI Channel 1 in most UIs).
- **Velocity Mapping**: Since Note Off is velocity 0, ensure your synth treats velocity 0 as note release (most do).
- **Port Routing**: If your DAW doesn’t see the generator’s port, use a virtual MIDI loopback driver and enable “Thru” routing.

## Troubleshooting

- **No Sound**:
- Confirm the correct MIDI port and channel are selected in your synth.
- Check that the virtual loopback utility is running.

- **Stuck Notes**:
- Ensure the all-notes-off loop runs on exit; if not, manually send an “All Notes Off” CC 123 or restart your synth.

- **Incorrect Velocity**:
- The generator uses a fixed velocity of 100 for Note On. If your synth maps velocity to timbre, adjust in the synth’s settings or modify the source.

With this setup, your DAW or hardware synth will receive standard MIDI Note On and Note Off messages as generated by the minimal-music pattern generator, allowing you to integrate it seamlessly into your music workflow.
